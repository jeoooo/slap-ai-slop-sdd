Principles for this project:
- Fixed stack: SvelteKit (Svelte 5, TypeScript) and Ark UI (`@ark-ui/svelte`). No other frameworks or UI libraries. Plain CSS.
- No backend: no server routes, no database, no external API calls, no API keys or .env.
- Mobile-first. Accessible by default (one h1, ordered headings, alt text, contrast >= 4.5:1, visible keyboard focus, dialogs and accordions work with the keyboard).
- No health claims. All copy is real, with no lorem ipsum. Sample testimonials are labelled as sample.
- Fictional brand, clearly labelled as a demo site.
- Only fonts and assets that need no API key.
